# AI for Competence Development Lab website

A responsive, multi-page static website designed for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About the Lab
- `people.html` — People
- `research.html` — Research
- `projects.html` — Projects
- `publications.html` — Publications
- `news.html` — News & Events
- `contact.html` — Contact

## Publish using GitHub Pages

1. Sign in to GitHub or create an account at https://github.com/.
2. Create a **new public repository** named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Keep the repository initialisation options unchecked if you are uploading these files as a batch.
4. Download and unzip this website package on your computer.
5. Open the new repository on GitHub. Choose **Add file → Upload files**.
6. Upload the contents of the unzipped folder (the HTML files, `assets` folder and this README). Make sure `index.html` is at the repository root, not inside an extra nested folder.
7. Enter a commit message such as `Add lab website` and click **Commit changes**.
8. Open the repository's **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
9. Select branch **main** and folder **/(root)**, then click **Save**.
10. Wait a few minutes. Your website should be available at `https://YOUR-USERNAME.github.io/`.

## Updating the website

- Edit page content by opening the relevant `.html` file in GitHub and selecting the pencil icon.
- Shared colours, typography, spacing and layout are in `assets/css/style.css`.
- Mobile navigation and the automatic footer year are in `assets/js/main.js`.
- After committing an edit, GitHub Pages will publish the update automatically. It can take a few minutes.

## Before making the site public

This is a starter template. Replace all sample text with approved Lab information, real people, publications, project details and contact information. The colour palette is an NIE-inspired approximation, not an official brand specification. No official NIE logo is included. Confirm institutional naming, affiliation and brand usage with NIE before presenting the site as an official institutional website.

## Custom domain (optional)

If you later want a custom domain, configure it under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions. You do not need a custom domain to use the `YOUR-USERNAME.github.io` address.
